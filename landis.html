During my co-op rotation in the GE Lab, I worked across software, electrical test systems, instrumentation, PCB design, and automation for electrical energy-meter testing equipment.

Database Query Agent

I developed a web application that accepts natural-language questions within the context of a connected SQL database and returns the corresponding database results. The application uses a LangChain SQL agent to translate user questions into SQL queries and present the results.

Mini-Blue

Mini-Blue is a compact electrical energy-meter testing setup built around an RX-30 Radian standard—a precision reference instrument used to measure and verify meter performance—along with voltage and current sources that provide controlled test signals. I ported the user interface I had developed for the Big Blue electrical meter-testing fixture to Mini-Blue, then adapted and debugged the code for the smaller system and its hardware.

Mini-Blue fixture used to test electrical energy meters and control test sources.

Mini-Blue demonstration showing the adapted user interface and electrical meter test setup.

Optical Probe Redesign

Optical probes provide a communication link for reading data from and writing data to electrical energy meters through their optical interface. As the meters were updated to sample data at 1 MHz, the existing probes needed to be redesigned to support the higher data rate. I contributed to the redesign by working on the PCB layout and the mechanical fit between the circuit board and the probe-head shell. I also added the circuit to an LTspice simulation and evaluated the received optical signal before and after amplification.

PCB and mechanical layout work for the optical probe used to communicate with electrical energy meters.

LTspice simulation of the optical probe receive and amplification circuitry.

Receive-signal waveform showing the optical probe signal before and after amplification.

Universal Socket Routing Board

The universal socket routing board is a relay-controlled power-routing board for an electrical energy-meter testing fixture. It connects the Big Blue fixture's power sources to the appropriate socket contacts for different meter form factors and power configurations. This makes the fixture adaptable to different electrical meter designs without manually rewiring the power connections for each setup. I worked on the board layout and assembly, and wrote the I²C control script that operates its relays and integrates the board with the Big Blue fixture.

Universal socket routing boards that configure power connections for different electrical meter form factors.

Routing-board demonstration: selecting an electrical meter form and power configuration, then using relay logic to route power to the corresponding socket contacts.

Meter Testing Interface

I developed a Python UI that interfaces with an electrical energy-meter testing fixture. The UI communicates with an Arduino, which translates commands into SCPI commands sent to the voltage and current sources used to test the meters. The original interface was written in C and I was tasked with translating it into Python.

Current Transformer Board

I also worked on the design of a current-transformer board and wrote the control software for its ballast resistors. The board provides variable control of output current when attached to three CTs, supporting currents up to 600 amps.
