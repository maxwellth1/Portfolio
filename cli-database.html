CLI Mini Database

A lightweight command-line database application built around JSON data, designed to ingest structured records and make them searchable from a terminal interface.

View GitHub Repository

What it does

The application loads JSON datasets into the program and provides command-line operations for loading files, selecting a dataset, viewing records, and searching across fields. The project is designed to make structured data exploration possible without needing a full database server.

Implementation

JSON ingestion

Uses a JSON library to parse structured datasets and turn them into searchable records.

CLI interface

Provides terminal commands for interacting with the database and inspecting loaded data.

Search

Supports searching records across their available fields rather than being tied to one fixed schema.

Terminal UI

Built as a C++ application with a focus on a practical command-line workflow.

Project Focus

This project has been an exercise in C++ application structure, data parsing, command-line interfaces, and designing a small searchable data system from the ground up.
